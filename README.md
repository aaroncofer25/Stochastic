# Stochastic Experiments

This repository contains small simulations exploring Markov chains, Brownian motion,
and a simple implementation of Pollard's p-1 integer factorization algorithm.

## Usage

Run the Python scripts directly with `python <script>.py`. Jupyter notebooks can be
opened with JupyterLab or another compatible interface.

Scripts include:

- `markov.py`, `markov1.py`, `markov2.py`, `markov3.py`, and `markov_4.py` –
  experiments with discrete-time Markov chains and related stochastic processes.
- `pollard_p_minus1.py` – demonstrates the Pollard p-1 factoring technique.
- `temp.py` and `test.py` – assorted small calculations.

Example:

```bash
python markov.py
```

## Development

This project has no external dependencies beyond `matplotlib` for plotting. A
basic `.gitignore` is included to exclude common Python cache files and Jupyter
outputs.
